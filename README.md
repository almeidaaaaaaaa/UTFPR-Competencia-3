🚀 Passo a Passo: Preparação do Ambiente
Siga as etapas abaixo para configurar o Java, o servidor e a IDE em sua máquina.

1. Kit de Desenvolvimento (JDK)
O primeiro passo é garantir que o motor do Java esteja instalado.


Instalação: Baixe e instale o JDK 25 ou uma versão superior.  


Download: Oracle JDK Downloads.  

2. Servidor de Aplicação (Apache Tomcat)
Precisamos de um servidor para rodar nossa aplicação web.


Download: Acesse o site do Apache Tomcat 11.  


Preparação: Baixe o arquivo .zip, descompacte-o em uma pasta de sua preferência (ex: C:\Servers\Tomcat) e guarde esse local.  

3. Ambiente de Desenvolvimento (NetBeans)
A IDE é onde a mágica do código acontece.


Instalação: Baixe e instale o NetBeans através do site da Codelerity.  

⚙️ Configurando o Tomcat no NetBeans
Agora vamos "apresentar" o servidor que você baixou para a sua IDE:

No NetBeans, vá até o menu superior e selecione Tools (Ferramentas) > Servers (Servidores).  

Clique em Add Server (Adicionar Servidor) e escolha a opção Apache Tomcat.  

Em Server Location, aponte para a pasta onde você descompactou o Tomcat no Passo 2.  


Credenciais de Acesso: Defina tanto o Username quanto o Password como admin.  

🛠️ Executando o Projeto
Com tudo configurado, é hora de colocar o código para rodar:

Baixe o arquivo .zip do projeto diretamente do GitHub.  

No NetBeans, vá em File > Open Project (Abrir Projeto) e selecione a pasta do projeto que você baixou.  

Para rodar a aplicação: clique com o botão direito sobre o nome do projeto na aba lateral e selecione a opção Run (Executar).
